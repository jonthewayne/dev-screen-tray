Dev Screen

One-click remote-in to the dev Mac's screen (over Tailscale), plus its physical-display controls.

Menu

Dev Mac: reachable / unreachableLive status (quick TCP check to the dev Mac over Tailscale)
Connect (Screen Share)Opens macOS Screen Sharing to the dev Mac and blacks out its physical screen — nobody there sees your session; your remote view stays bright
Stop Screen Share(Shown while sharing) closes the Screen Sharing window, then locks and blacks out the dev Mac
Settings ▸Restore Brightness · Start at Login · Guide

Setup on the dev machine (one-time)

For this app to drive it, the dev Mac needs:

Tailscalesigned in; dev Mac awake + lid open. Works from anywhere on the tailnet, not just same Wi-Fi.
Screen SharingSystem Settings → General → Sharing → Screen Sharing on. (Leave Remote Management off.)
Remote Login + your SSH keyRemote Login (SSH) on, and this Mac's public key in the dev Mac's ~/.ssh/authorized_keys — used for the brightness & lock commands.
brightness CLIinstalled on the dev Mac at /usr/local/bin/brightness (e.g. brew install brightness) — needed for true-0 Black Out / Restore.
Lock on sleepdev Mac → System Settings → Lock Screen → "Require password after display off" → Immediately, so Lock / Stop Screen Share actually locks it.

Config (dev Mac user/IP) lives in dev-screen-ctl. If the menu says unreachable, the dev Mac is asleep/off or off the tailnet.
