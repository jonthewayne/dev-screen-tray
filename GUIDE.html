Dev Screen

One-click remote-in to the dev Mac's screen (over Tailscale), plus its physical-display controls.

Menu

Dev Mac: reachable / unreachableLive status (quick TCP check to the dev Mac over Tailscale)
Connect (Screen Share)Opens macOS Screen Sharing to the dev Mac's desktop
Connect + Black OutConnects, then sets the dev Mac's physical brightness to 0 — nobody there sees your session; your remote view stays bright
Black Out Screen / Restore BrightnessToggle the dev Mac's physical brightness (0 ↔ full)
Lock Dev MacBlanks + locks the dev Mac (display sleep; locks with its password setting)
Settings ▸Start at Login · Guide (this window)
QuitCloses the app (nothing to tear down — actions are one-shot)

Requirements

  • The dev Mac must be awake, lid open, and on Tailscale (works from anywhere — not just same Wi-Fi).
  • Screen Sharing enabled on the dev Mac; SSH key from this Mac authorized there (for brightness/lock).
  • The brightness CLI installed on the dev Mac (for Black Out / Restore).

Config (dev Mac user/IP) lives in dev-screen-ctl. If it says unreachable, the dev Mac is asleep/off or off the tailnet.
