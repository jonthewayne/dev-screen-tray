Dev Screen

One-click remote-in to the dev Mac's screen (over Tailscale), plus its physical-display controls.

First time: pick your dev machine

The first time you hit Connect (or open Settings ▸ Dev Machine), it walks you through a one-time setup: choose a Mac from your Tailscale network and enter the login username that Mac uses. That's it — no password is stored: the control commands use your SSH key, and macOS's own Screen Sharing prompts for (and keychains) the login password. Your choice is saved to ~/.config/dev-screen/config; change it anytime under Settings.

Headless by design

This treats the dev Mac as a headless box. Connect blacks out its physical screen on purpose — so anyone standing near it can't see your session, while your remote view stays fully bright. While connected, the app checks every few seconds and re-applies zero brightness if macOS wakes or brightens the display. Need its own screen visible again (e.g. someone's using it in person)? Flip Settings ▸ Restore Brightness (which toggles back to Black Out Screen), which pauses that enforcement for the current session. Choose Black Out Screen to resume it.

A note on physical security

Black Out controls brightness; it is not a security boundary or a separate login session. Screen Sharing still shares the session on the physical display. For a dev Mac kept in a private spot, the enforced dark display is usually sufficient. Pair it with Require password: Immediately (below) so the machine locks when the sharing session ends.

Setup on the dev machine (one-time)

For this app to drive it, the dev Mac needs:

Tailscalesigned in; dev Mac awake + lid open. Works from anywhere on the tailnet, not just same Wi-Fi.
Screen SharingSystem Settings → General → Sharing → Screen Sharing on. (Leave Remote Management off.)
Remote Login + your SSH keyRemote Login (SSH) on, and this Mac's public key in the dev Mac's ~/.ssh/authorized_keys — used for the brightness & lock commands.
brightness CLIinstalled on the dev Mac at /usr/local/bin/brightness (e.g. brew install brightness) — needed for true-0 Black Out / Restore.
Lock on sleepdev Mac → System Settings → Lock Screen → "Require password after display off" → Immediately, so Lock / Stop Screen Share actually locks it.

Which Mac you target is set in the app (Settings ▸ Dev Machine) and saved to ~/.config/dev-screen/config. If the menu says unreachable, the dev Mac is asleep/off or off the tailnet.
